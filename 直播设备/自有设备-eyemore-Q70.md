## 3. 室内绿幕效果判断

### 效果上限构成

| 因素 | 权重 | 要点 |
|------|------|------|
| 绿幕 + 灯光 | **约 60%** | 绿幕单独打光、均匀无皱；人物面光 + 轮廓光；人离幕 **1.5～2 m** |
| 设备 + 软件 | **约 40%** | Q70 内置抠像，布光正常时边缘可较干净 |

### 常见问题与对策

| 现象 | 对策 |
|------|------|
| 脸发绿、绿边 | 人后退；加面光；减绿幕反光 |
| 头发/手臂边缘毛糙 | 绿幕打匀；微调抠像参数；避免快大幅度动作 |
| 衣服被抠掉 | 勿穿绿色/黄绿色 |

### 30 分钟试播清单

1. 绿幕两侧各一盏灯打幕，正前方主光 + 侧后轮廓光  
2. 人退后 1.5 m+，穿非绿色衣服  
3. Q70 自带导播软件开抠像，换武隆/天生三桥背景图  
4. 检查：**头发边缘、手臂快移、脸部是否发绿**

试播三项均 OK → 室内绿幕可直接用 Q70，不必为室内再租拍摄端。

## 4. 与租赁方案对比（武隆项目）

项目需求：**户外天生三桥 + 室内绿幕**，租期 3 个月。详见 `设备租赁上下文.md`。

| 对比项 | 自有 eyemore Q70 | 租赁（如租小杨/昊天/猫冬等） |
|--------|------------------|------------------------------|
| 画质/虚化 | 较好（M4/3 级一体机） | **A7M4 全画幅 / FX30** 通常更好 |
| 抠像 | 内置，上手简单 | OBS/直播伴侣 + 独显，可调空间大 |
| 户外天生三桥 | **弱**（非户外移动方案） | FX30+Power / 5G 路由等更匹配 |
| 室内绿幕 | **可用，中上** | 专业灯 + 绿幕，上限更高 |
| 成本 | 已有设备，室内段 **0 租费** | 全套约 1660～1997 元/月 |
| 复杂度 | 低，一台搞定室内 | 设备多，统筹成本高 |

### 组合建议（2026-06-02 讨论结论）

| 场景 | 建议 |
|------|------|
| 室内绿幕试播、日常讲解 | 优先用 **Q70** |
| 户外景区出镜、要电影感统一观感 | 仍走 **租赁移动方案** |
| 签约租赁时 | 可评估是否 **减配室内拍摄端/电脑**，仅租户外所需（**需与商家确认**） |
