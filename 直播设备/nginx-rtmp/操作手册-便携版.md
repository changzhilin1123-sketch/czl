# 无人机 RTMP 中继 · 便携操作手册

> **适用**：任意 Windows 10/11 工作电脑（复制整个 `nginx-rtmp` 文件夹即可）  
> **用途**：无人机 → 本机 RTMP → VLC → 抖音直播伴侣「窗口采集」画中画  
> **不依赖**：武隆项目路径、OBS、固定盘符

---

## 一、拷贝到新机

1. 复制整个文件夹 `nginx-rtmp` 到新机（U 盘、桌面、`D:\tools\` 均可）
2. 路径可含中文，**建议不要有空格**
3. 文件夹结构：

```
nginx-rtmp/
├── 操作手册-便携版.md    ← 本文档
├── 1-安装.bat
├── 2-启动.bat
├── 3-验证.bat
├── 4-停止.bat
├── conf/nginx.conf
├── scripts/              ← 脚本（勿删）
└── runtime/              ← 首次安装后生成（含 nginx.exe）
```

---

## 二、首次使用（每台电脑一次）

1. 双击 **`1-安装.bat`**（需联网，下载约 2.4MB）
2. 双击 **`2-启动.bat`**
3. 双击 **`3-验证.bat`**，应显示 **PASS=5  FAIL=0**

### 已有 nginx 安装目录时（可选）

若本机已在 `D:\tools\nginx-rtmp` 装过：

```bat
copy scripts\paths.local.bat.example scripts\paths.local.bat
notepad scripts\paths.local.bat
```

将 `ROOT=` 改为已有目录，跳过重复下载。

## 三、日常启停

| 操作 | 双击 |
|------|------|
| 启动 | `2-启动.bat` |
| 验证 | `3-验证.bat` |
| 停止 | `4-停止.bat` |

命令行等效：

```bat
cd /d <你的路径>\nginx-rtmp
2-启动.bat
3-验证.bat
```

## 四、地址说明

| 用途 | 地址 |
|------|------|
| **RC2 推流** | `rtmp://<本机WLAN_IP>:1935/live/drone` |
| **VLC 本机拉流** | `rtmp://127.0.0.1:1935/live/drone` |
| **状态页** | `http://127.0.0.1:8080/stat` |

`3-验证.bat` 会打印各网卡对应的 RTMP 地址。

**注意**：遥控器 **不能用 127.0.0.1**；须与电脑 **同一 WiFi**（公司 AP 隔离时改手机热点）。

---

## 五、无人机推流（RC2 / 普控）

1. RC2 **插入麦克风**（无麦无法开播）
2. RC2 连接与电脑 **同网段** WiFi
3. DJI Fly → **···** → **图传** → **直播平台** → **RTMP**
4. 地址：`rtmp://<IP>:1935/live/drone`（推流码留空）
5. RC2 分辨率 **720p** 正常｜码率先 **3 Mbps**
6. **开始直播** → 角标变红

---

## 六、VLC 验证

1. 先 RC2 推流成功
2. VLC → 媒体 → 打开网络串流 → `rtmp://127.0.0.1:1935/live/drone`
3. 有画面后再配置直播伴侣

---

## 七、直播伴侣合流

1. **视频捕获设备** → 采集卡（地面主画面）
2. **窗口采集** → 选 **VLC** 窗口（勿最小化）
3. 无人机画中画缩至角落；**音频只用麦克风**
4. 预览 → **开始直播**（仅伴侣推抖音，无人机不直推抖音）

---

## 八、故障排查

| 现象 | 处理 |
|------|------|
| `/usr/local/nginx/` 报错 | 必须用 `2-启动.bat`（自带 `-p` 参数） |
| 验证 FAIL | 先 `2-启动.bat` 再 `3-验证.bat` |
| RC2「直播异常」 | 同 WiFi、防火墙、IP 是否为验证页打印的 WLAN 地址 |
| VLC 无法打开 MRL | 先推流；确认 `3-验证.bat` 全 PASS |
| 伴侣窗口黑屏 | VLC 勿最小化；重选窗口采集 |
| 安装下载失败 | 浏览器打开 README 中的 GitHub Releases 手动解压到 `runtime\` |

---

## 九、技术说明

- **nginx 安装目录**：默认 `<nginx-rtmp>\runtime\`，可通过 `scripts\paths.local.bat` 自定义
- **配置模板**：`conf\nginx.conf`（每次启动会同步到 runtime）
- **流名**：`live` 应用下 `drone` 流，可改 conf 中路径，RC2 地址需同步修改
