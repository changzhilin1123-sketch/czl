## 5. 直播技术方案（2026-06-17 定稿方向）

### 5.1 信号链路 · 节约成本版

```
【地面主路】A7M5 → HDMI → 美乐威 4K Plus×1 → Y7000 → 抖音直播伴侣（采集卡源）
【空中第二路】Mini 4 Pro + RC-N2 → DJI Fly RTMP → 本机局域网 RTMP（如 nginx-rtmp）
              → VLC/ffplay 窗口 → 伴侣「窗口采集」→ 画中画叠加
【音频】猛玛/大疆一拖二 → 伴侣麦克风
【上行】聚合路由（Y7000 有线/WiFi）≥2 卡；无人机上行走飞手手机 4G/5G，不走聚合路由
【推流】伴侣一路编码推抖音（1080p/30，码率 4000–6000 kbps）
```

> **不用 OBS**；无人机**不可** RTMP 直推抖音（会与伴侣争用同一直播间推流地址）。

### 5.2 聚合路由 · SIM 卡数量（推算）

| 档位 | 卡数 | 适用 | 说明 |
|:---:|------|------|------|
| **最低** | **2** | 信号尚可的试播 | 移动+联通（或+电信）混插；1080p 码率 ≤4500 kbps |
| **推荐** | **3** | 天生三桥峡谷常态 | 移动+联通+电信；深谷遮挡多，单/双卡易掉帧 |
| 不推荐 | 1 | — | 峡谷弱网，难以稳定 1080p |

- 伴侣单路输出约需上行 **5–8 Mbps**（含协议开销）；双路素材合成后仍是一路推流。
- **已确认**：猫冬多网聚合路由器 **最多 4 卡槽**；天生三桥 **3 卡（移动+联通+电信）** 可落地。

### 5.3a 无人机 · 测试机与正式机直播分辨率

| 配置 | 直播分辨率 | 说明 |
|------|-----------|------|
| **Mini 5 Pro + RC2**（当前测试） | **720p** | **正确**；RC2 硬件限制，无法选 1080p |
| **Mini 4 Pro + RC-N2 普控**（正式） | **1080p/60**（图传）· RTMP 可选 1080p | 正式方案画质更高 |

> RC2 直播前须 **插入麦克风**（大疆官方要求，否则无法开播）。RC2 需连 **WiFi**（手机热点或聚合路由 WiFi）才能 RTMP 推流。

### 5.6 无人机无线进直播伴侣 · 操作步骤（RTMP 局域网中继）

**原理**：无人机不直推抖音 → 推本机局域网 RTMP → VLC 窗口 → 伴侣「窗口采集」画中画；地面相机走采集卡。全程不用 OBS。

#### A. 一次性准备（Y7000）

1. 安装 **抖音直播伴侣**（最新版）、**VLC**（或 ffplay）。
2. 安装并启动本机 **RTMP 服务** → **`nginx-rtmp/操作手册-便携版.md`**（复制整个 `nginx-rtmp` 文件夹到任意工作电脑；`1-安装.bat` → `2-启动.bat` → `3-验证.bat`）。

#### B. 无人机端（Mini 5 Pro + RC2）

1. 飞机、RC2 开机；固件与 **DJI Fly ≥ V1.16.0**。
2. **RC2 插入麦克风**（3.5mm 或 USB，按 RC2 接口）。
3. RC2 连接 **WiFi**（与 Y7000 同网段：聚合路由 WiFi 或手机热点共享给 RC2）。
4. DJI Fly → 飞行界面 → **···** → **图传** → **直播平台** → **RTMP**。
5. **RTMP 地址**填：`rtmp://192.168.8.100:1935/live/drone`（地址与流名用 `/` 拼接）。
6. **分辨率**：RC2 仅 **720p**（正常）｜**码率**：建议 **3 Mbps** 试播，稳定后可试 5 Mbps。
7. 点 **开始** → 倒计时后画面角标变红即推流成功。
8. 在 Y7000 用 VLC 验证：媒体 → 打开网络串流 → 同上地址，能出画面再继续。

#### C. 直播伴侣 · 双路合流

1. 打开伴侣 → 登录抖音账号 → 选直播类型（实景/电商等）。
2. **主画面 · 相机**：添加素材 → **视频捕获设备** → 选美乐威采集卡 → A7M5 画面。
3. **子画面 · 无人机**：添加素材 → **窗口采集** → 选 VLC 播放窗口（先打开 VLC 全屏或固定大小窗口）。
4. 调整层级：无人机窗口缩小至角落 **画中画**；地面机位为主画面。
5. **音频**：选 **麦克风**（一拖二接收机），勿采 VLC 静音轨。
6. 伴侣设置：输出 **1080×1920 竖屏** 或 **1920×1080 横屏**（与账号习惯一致）；视频码率 **4000–6000 kbps**；帧率 **30fps**。
7. 先 **预览** 确认双画同步、无明显延迟（窗口采集通常 +0.5–2s，可接受则开播）。
8. 点 **开始直播** → 伴侣一路推抖音。

#### D. 结束与注意

| 项 | 说明 |
|----|------|
| 禁止 | 无人机 RTMP **直填抖音推流地址**（与伴侣争用同一直播间） |
| 网络 | 无人机上行走 **RC2 所连 WiFi**；与聚合路由 SIM 无关；WiFi 须能访问 Y7000 局域网 IP |
| 测试差异 | 当前 RC2 仅 720p；正式 RC-N2 可 1080p，画中画清晰度会提升 |
| 合规 | **UOM 空域已验证通过**（天生三桥可申请空域） |

### 5.3 户外面灯（参考直播点位参考.jpg）

**环境**：天福官驿观景平台；峡谷深、背景亮、前景人物易逆光；无市电，需电池供电、便携上山。

| 项 | 推荐 |
|----|------|
| **型号** | **神牛 ML150Bi** + **ML-BA 电池** + **ML-Z 变焦反光杯**（或柔光罩） |
| **理由** | 150W 聚光约 61000 lux@1m，能压住峡谷逆光；裸灯约 770g，可手持/灯架 |
| **续航** | ML-BA 全功率约 **40 min**；长播备第二块 ML-BA 或降功率至 60–70% |
| **省钱备选** | 神牛 **ML80Bi**（约便宜一档；逆光可能偏暗，需现场试） |
| **不推荐** | 凛光 300W×4 搬户外（无电源、过重）；智云 X100 手柄电池仅约 34 min 满功率 |
