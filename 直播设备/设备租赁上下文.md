## 5. 户外直播技术备忘

### 5.1 主播 + 无人机 OBS 合流

```
相机 → 采集卡1 → OBS
御3E → RC Pro → mini-HDMI → 采集卡2 → OBS  （或 Pilot2 RTMP → 媒体源）
OBS 一路推流 → 抖音
地面网络：聚合路由；无人机上行：飞手 4G/5G（RTMP 时）
```

### 5.2 RC Pro mini-HDMI

| 项 | 说明 |
|----|------|
| 接口能力 | 官方支持最高 **4K** 输出 |
| 实际图传 | 多为 **1080p**（30/60fps） |
| 线材 | **Mini HDMI 公 → HDMI 公**（绿联 HDMI 2.0 可用）；非 Micro HDMI |
| 设置 | 系统设置→显示→HDMI 开启；Pilot 2→图传→**仅相机画面** |
